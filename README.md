# portfolio-website

This repository contains an original portfolio app and a pair of clean scaffolds.

Clean copies:

- `frontend-clean/` — a minimal, organized Next.js (TypeScript) frontend scaffold. See `frontend-clean/README.md` for instructions.
- `backend-clean/` — a minimal TypeScript Express backend scaffold. See `backend-clean/README.md` for instructions.

To copy image assets from the original frontend into the clean frontend, run from the repo root in PowerShell:

```powershell
# Copies images from frontend/public -> frontend-clean/public
.\copy-images.ps1
```

# FGCU Degree Flowsheet Tool - Quick Start Guide

## For Non-Technical Users

This guide helps FGCU staff and faculty use and customize the degree flowsheet tool **without coding experience**.

## What You Can Do

### View the Flowsheet
1. Open the website in your browser
2. You'll see the interactive degree flowsheet
3. Hover over any course to see prerequisites and related courses
4. Click on the course code to see details

### Understand the Display

**Color Coding:**
- 🟣 **Purple** - Normal courses
- 🟨 **Yellow** - Selected course
- 🔵 **Blue** - Prerequisites
- 🟢 **Green** - Corequisites (take at same time)
- 🔴 **Red** - Postrequisites (depend on this course)

**Top Section:**
- Program name and description
- Total credits required
- Effective academic year
- Credit acknowledgments

**Main Grid:**
- Left to right: Semesters (Fall → Spring)
- Top to bottom: Years 1 through 4
- White boxes: Individual courses with credits

## For Administrative Staff

### Updating Course Information

If you need to update existing programs, contact your IT/Development team with:

1. **Course Changes**
   - Course code changes
   - Course name updates
   - Credit hour changes

2. **Prerequisite Updates**
   - New prerequisites
   - Removed prerequisites
   - Corrected prerequisites

3. **Layout Changes**
   - New courses added
   - Courses removed
   - Semester moved

4. **Program Information**
   - Total credits updated
   - New effective academic year
   - Description changes

### Adding New Degree Programs

Provide IT team with:
- Current degree flowsheet (PDF or similar)
- Course list with codes, names, and credits
- Prerequisites for each course
- Official course catalog entries
- Program code (2-4 letters)
- Total credit hours
- Effective start year

### Deployment & Updates

Once updated:
1. Changes are tested in development
2. Website is updated
3. New version goes live (usually takes 1-2 hours)
4. Advisors can access immediately

## For Academic Advisors

### Using With Students

1. **Show the Flowsheet**
   - Display during advising appointments
   - Students see their path to graduation
   - Discuss course sequencing

2. **Explain Prerequisites**
   - Use the highlighting to show chains
   - Discuss why prerequisites exist
   - Plan around prerequisites

3. **Address Questions**
   - "What's a prerequisite?" → Blue highlighted courses
   - "Can I take this now?" → Check prerequisites
   - "What can I take next?" → Look at future semesters

4. **Print or Screenshot**
   - Can take screenshots for records
   - Good for in-person or remote advising

### Common Questions from Students

**"Can I take course X now?"**
- Check the prerequisites (blue courses)
- Verify student has taken all prerequisites
- Consider corequisites (green courses)

**"What courses prepare me for X?"**
- Hover over course X
- Look at blue prerequisites
- These are the preparatory courses

**"How many credits this semester?"**
- Look at the number in the semester header
- Shows total credits for that semester
- Helps with course load planning

## Frequently Asked Questions

**Q: Why is this course shown before that one?**
A: Courses are arranged by semester. Prerequisites determine which comes "first." Earlier courses have no prerequisites; later courses depend on earlier ones.

**Q: Can students take prerequisites and dependent courses together?**
A: Only if marked as corequisites (green). If a course needs a prerequisite (blue), it must be taken first.

**Q: What if a course isn't in the flowsheet?**
A: All required courses are included. If you find an error, contact your department chair.

**Q: How often is this updated?**
A: When the curriculum changes (usually annually at course review time).

**Q: Can I share this with students?**
A: Yes! The website is public. Everyone can access it. The URL is ideal for emails and course materials.

**Q: What if I see an error?**
A: Report it immediately to your department. Document what's wrong and provide the correct information.

## Common Issues & Solutions

### "The page won't load"
- Check internet connection
- Try refreshing (F5 or Ctrl+R)
- Try a different browser
- Clear browser cache

### "Colors aren't showing correctly"
- Refresh the page
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser

### "I see old course information"
- Refresh the page (Ctrl+F5)
- Clear browser cache
- Contact IT if problem persists

### "Mobile view looks wrong"
- Rotate device to landscape
- Try pinch/zoom to see better
- Report to IT with device type
